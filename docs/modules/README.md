# 모듈 문서 사용법

각 파일은 하나의 모듈을 설명한다.

읽는 순서:
1. `../MODULE_MAP.md`에서 주 모듈을 찾는다.
2. 이 디렉토리의 해당 모듈 문서를 읽는다.
3. 변경이 다른 모듈에 닿으면 협업 모듈 문서도 읽는다.
4. 기능 추가는 `../EXTENSION_GUIDE.md`를 따른다.
5. 운영 영향은 `../OPERATIONS.md`에 반영한다.

모듈 문서의 공통 섹션:
- 책임
- 소유 범위
- 소유 데이터
- 소유하지 않는 것
- 계약
- 확장 포인트
- 테스트
- 운영 고려사항

이 구조의 목적은 큰 기능을 붙일 때도 경계가 흐려지지 않게 하는 것이다. 기능이 두 개 이상의 모듈 책임을 동시에 크게 바꾸면, 먼저 작업 패키지를 분리한다.
