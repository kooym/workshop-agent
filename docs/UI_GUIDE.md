# UI 디자인 가이드

## 디자인 원칙

1. **도구처럼 보여야 한다** — 매일 쓰는 대시보드처럼. 마케팅 페이지가 아니다.
2. **포스트잇이 주인공** — UI 요소는 배경에 녹아들고, 참석자가 만든 콘텐츠(포스트잇)가 시각적 중심.
3. **워크샵 흐름이 보여야 한다** — 현재 어떤 단계인지, 다음에 뭘 해야 하는지 즉시 파악 가능.

---

## AI 슬롭 안티패턴 — 하지 마라

| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |

## 레이아웃

### 전체 구조

```
┌─────────────────────────────────────────────────────┐
│  Header: 워크샵 제목 | 단계 표시 | 참석자 수 | 설정  │
├────────────┬────────────────────────────────────────┤
│            │                                        │
│  Sidebar   │          Main Canvas                   │
│  (좌측)    │          (중앙)                         │
│            │                                        │
│  - 단계 목록│  Stage별 콘텐츠:                        │
│  - 참석자   │  - 포스트잇 보드                        │
│  - 타이머   │  - 클러스터 뷰                          │
│  - 퍼실 컨트롤│  - 투표 화면                          │
│            │  - AX 과제 목록                         │
│            │  - PRD 에디터                           │
│            │                                        │
├────────────┴────────────────────────────────────────┤
│  Footer: 입력 영역 (Stage 1) / 투표 현황 (Stage 3)   │
└─────────────────────────────────────────────────────┘
```

- 전체 너비: max-w-screen (전체 화면 사용, 보드 공간 최대화)
- 사이드바 너비: w-64 (256px), 접기 가능
- 정렬: 좌측 정렬 기본
- 간격: gap-3~4, 섹션 간 space-y-6

### 반응형
- **데스크톱 (1024px+)**: 사이드바 + 메인 캔버스 2단 레이아웃
- **태블릿 (768px~1023px)**: 사이드바 숨김, 헤더에 단계 표시 축약
- **모바일**: MVP 지원 안 함 (데스크톱 브라우저 안내 메시지 표시)

## 컴포넌트

### 포스트잇 (StickyNote)

```
┌──────────────────────┐
│ 포스트잇 내용           │  ← 카테고리별 배경색
│ (최대 200자)           │
│                      │
│ ─────────────────    │
│ 👤 작성자 | ❤️ 3      │  ← 하단: 작성자 + 리액션
└──────────────────────┘
```

- 크기: w-48 h-auto (min-h-32)
- 모서리: rounded-lg
- 그림자: shadow-md (떠있는 느낌)
- 호버: scale-[1.02] transition
- 텍스트: text-sm leading-relaxed
- 카테고리 배경색 적용 (위 포스트잇 색상 표 참조)

### 클러스터 그룹 (ClusterGroup)

```
┌─ 프로세스 비효율 ─────────────────────┐
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│  │note│ │note│ │note│ │note│  ...    │
│  └────┘ └────┘ └────┘ └────┘        │
│                                      │
│  📊 5개 포스트잇 | 투표 12표           │
└──────────────────────────────────────┘
```

- 보더: border border-neutral-700 rounded-xl
- 헤더: 클러스터명 (text-lg font-semibold) + 요약 (text-sm text-neutral-400)
- 내부 포스트잇: flex-wrap gap-3
- 하단: 통계 (포스트잇 수, 총 투표 수)

### 투표 카드 (VotingCard)

```
┌──────────────────────────────────────┐
│  프로세스 비효율                       │  ← 클러스터/포스트잇 제목
│  "수작업이 너무 많다..." (요약)        │
│                                      │
│  ████████████░░░░░ 12표 (40%)       │  ← 결과 바 (공개 후)
│                                      │
│  [🔵] [🔵] [🔵]   ← 내 투표 (도트)   │
│  [투표하기]                            │
└──────────────────────────────────────┘
```

- 투표 도트: w-4 h-4 rounded-full bg-blue-500
- 결과 바: h-2 bg-blue-500 rounded-full (비율에 따라 너비)
- 투표 전: 도트만 표시 / 투표 후: 결과 바 + 퍼센트 표시

### 단계 네비게이션 (StageNav)

```
[1. 수집] ──── [2. 클러스터] ──── [3. 투표] ──── [4. 과제] ──── [5. PRD]
  ✅ 완료      🔵 진행중         ⚪ 대기       ⚪ 대기      ⚪ 대기
```

- 완료: text-green-500 + 체크 아이콘
- 진행중: text-blue-500 + 원형 인디케이터
- 대기: text-neutral-500
- 연결선: border-t border-neutral-700

### 카드 (범용)
```
rounded-lg bg-neutral-900 border border-neutral-700 p-4
```

### 버튼
```
Primary:  rounded-lg bg-white text-black px-4 py-2 hover:bg-neutral-200 font-medium
Secondary: rounded-lg bg-neutral-800 text-neutral-300 px-4 py-2 hover:bg-neutral-700
Danger:   rounded-lg bg-red-600 text-white px-4 py-2 hover:bg-red-700
Text:     text-neutral-400 hover:text-neutral-200
```

### 입력 필드
```
rounded-lg bg-neutral-900 border border-neutral-700 px-4 py-3 text-white
placeholder:text-neutral-500 focus:border-neutral-500 focus:outline-none
```

### 모달
```
fixed inset-0 bg-black/60     ← 오버레이 (blur 금지!)
rounded-xl bg-neutral-900 border border-neutral-700 p-6 max-w-lg mx-auto
```

## 애니메이션

허용하는 애니메이션만 나열. 그 외 모든 애니메이션 금지.

| 애니메이션 | 용도 | 설정 |
|-----------|------|------|
| fade-in | 포스트잇 새로 추가 시 | opacity 0→1, 300ms ease-out |
| scale-in | 투표 도트 찍을 때 | scale 0.8→1, 200ms ease-out |
| slide-up | 모달 열기 | translateY 8px→0, 300ms ease-out |
| pulse | AI 처리 중 로딩 | opacity 0.5↔1, 1.5s infinite |
