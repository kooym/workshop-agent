# PRD: Workshop Agent

## 목표

고객사의 pain point를 빠르게 실증(PoC/PoV)하여 사업화하기 위한 **비즈니스 엔비저닝 워크샵**을 디지털로 퍼실리테이션하는 웹 어플리케이션.

기존에 포스트잇과 화이트보드로 진행하던 워크샵 프로세스를 온라인으로 옮기고, AI를 활용하여 pain point 클러스터링·과제 도출·PRD 생성을 자동화한다.

---

## 사용자

### 퍼실리테이터 (Facilitator)
- 워크샵을 기획하고 진행하는 사람 (1명)
- 워크샵 생성, 단계 전환, 타이머 제어, AI 클러스터링 트리거, 최종 산출물 관리
- 전체 프로세스를 컨트롤하는 관리자 역할

### 참석자 (Participant)
- 고객사의 다양한 role과 team으로 구성된 사람들 (~10명)
- 초대 코드로 워크샵에 접속
- pain point/needs 기재, 투표, 피드백 제공
- 각자의 시각에서 업무 프로세스의 문제점과 니즈를 공유

---

## 워크샵 프로세스 (5단계)

### Stage 1: 수집 (Gather)
**목적**: 참석자 전원이 현재 업무 프로세스의 As-Is 상황, pain point, needs를 자유롭게 기재

**기능**:
- 온라인 보드에 디지털 포스트잇(스티키 노트) 생성
- 실시간 동기화 — 모든 참석자가 동시에 보드를 보며 각자 포스트잇 작성
- 익명/실명 선택 가능 (퍼실리테이터가 워크샵 생성 시 설정)
- 포스트잇 색상으로 카테고리 구분 (예: pain point = 빨강, needs = 파랑, idea = 초록)
- 타이머 — 퍼실리테이터가 수집 시간 설정 (예: 10분)
- 포스트잇에 "좋아요" 리액션 (간단한 공감 표시)

**참석자 경험**: 접속 → 보드에 포스트잇 붙이기 → 다른 사람의 포스트잇 실시간 확인 → 공감 리액션

### Stage 2: 클러스터링 (Cluster)
**목적**: 수집된 포스트잇들을 대주제별로 자동 분류하여 구조화

**기능**:
- **AI 자동 클러스터링**: Azure OpenAI를 활용하여 포스트잇 내용을 의미 기반으로 대주제(클러스터)로 자동 분류
  - 입력: 모든 포스트잇 텍스트
  - 출력: 클러스터명 + 각 포스트잇의 클러스터 할당 + 클러스터별 요약
- 클러스터 시각화 — 같은 클러스터의 포스트잇들이 그룹으로 묶여 표시
- **수동 조정**: 퍼실리테이터/참석자가 포스트잇을 다른 클러스터로 드래그앤드롭으로 이동 가능
- 클러스터 이름 편집 가능
- 클러스터 병합/분리 기능 (퍼실리테이터 전용)

**퍼실리테이터 경험**: "클러스터링 시작" 버튼 → AI가 분류 → 결과 확인 → 필요시 수동 조정 → 참석자에게 공유

### Stage 3: 투표 (Vote)
**목적**: 클러스터(대주제) 안에서 가장 심각한/중요한 문제점을 참석자 투표로 선별

**기능**:
- **도트 투표 (Dot Voting)**: 각 참석자에게 N개의 투표권 부여 (퍼실리테이터가 설정, 기본 3표)
- 클러스터 단위 또는 개별 포스트잇 단위 투표 (퍼실리테이터가 모드 선택)
- 실시간 투표 현황 — 투표 진행 중에는 결과 숨기기 옵션 (앵커링 방지)
- 투표 마감 후 결과 일괄 공개 (바 차트/히트맵 시각화)
- 투표 결과 기반 자동 순위 정렬
- 타이머 — 투표 시간 제한 설정 가능

**참석자 경험**: 클러스터별 포스트잇 확인 → 중요하다고 생각하는 항목에 투표 → 결과 확인

### Stage 4: AX 과제 도출 (Derive)
**목적**: 투표 결과 상위 pain point들을 기반으로, AI(Agent)로 해결 가능한 AX 과제를 도출

**기능**:
- 투표 상위 N개 클러스터/포스트잇 자동 선정 (퍼실리테이터가 N 설정)
- **AI 과제 도출**: 상위 pain point들을 분석하여 AX 과제 후보 자동 생성
  - 입력: 상위 pain point 클러스터 + 포스트잇 + 투표 결과
  - 출력: AX 과제명 + 해결 대상 pain point 매핑 + 예상 효과 + 구현 난이도
- 대주제 간 연계/중복 분석 — 여러 클러스터를 한 번에 해결할 수 있는 통합 과제 식별
- 과제별 상세 편집 (퍼실리테이터)
  - Agent가 수행할 핵심(core) 기능 정의
  - Sub 기능 목록
  - 우선순위 설정
- 참석자 피드백/코멘트 기능

**퍼실리테이터 경험**: 상위 pain point 확인 → "AX 과제 도출" 트리거 → AI 결과 검토 → 과제 수정/추가 → 참석자 피드백 수렴

### Stage 5: PRD 생성 (Generate)
**목적**: 확정된 AX 과제를 기반으로 개발 착수용 PRD를 자동 생성

**기능**:
- **AI PRD 생성**: 확정된 AX 과제 + 핵심 기능 + 참석자 피드백을 종합하여 PRD 초안 자동 생성
  - 출력 구조: 프로젝트 개요 / 목표 / 사용자 / 핵심 기능 상세 / 비기능 요구사항 / 우선순위 / 제외 사항 / 타임라인(선택)
- PRD 실시간 편집 (퍼실리테이터)
- PRD 버전 관리 (수정 이력)
- PDF/Markdown 내보내기
- 워크샵 전체 산출물 아카이브 (포스트잇 → 클러스터 → 투표 → 과제 → PRD 연결 추적)

## MVP 범위

### 포함 (MVP)
- F1: 워크샵 생성 (단일 워크샵)
- F2: 초대 코드 접속 (6자리 코드)
- F3: 실시간 포스트잇 보드 (텍스트 + 색상 + 실시간 동기화)
- F5: AI 클러스터링 (자동 분류 + 시각화)
- F7: 도트 투표 (기본 3표, 결과 공개)
- F8: AI AX 과제 도출 (기본 버전)
- F10: AI PRD 생성 (기본 구조)
- 워크샵 5단계 순차 진행 (퍼실리테이터가 단계 전환)

### 제외 (Post-MVP)
- F4: 타이머 (수동 진행으로 대체)
- F6: 수동 클러스터 조정 (AI 결과 그대로 사용)
- F9: 과제 상세 편집 (기본 텍스트 편집만)
- F11: PRD 버전 관리 / PDF 내보내기
- F12: 워크샵 아카이브
- 다중 워크샵 동시 진행
- 오프라인 모드
- 모바일 최적화 (데스크톱 우선)
- 녹화/녹음 연동
- SSO/기업 인증 연동

## 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| 동시 접속 | 최소 10명 동시 접속, 실시간 동기화 |
| 실시간 지연 | 포스트잇 생성/수정이 다른 참석자에게 1초 이내 반영 |
| AI 응답 시간 | 클러스터링: 30초 이내, AX 과제 도출: 30초 이내, PRD 생성: 60초 이내 |
| 브라우저 지원 | Chrome, Edge 최신 버전 (데스크톱) |
| 데이터 보존 | 워크샵 데이터는 세션 종료 후에도 유지 (최소 30일) |
| 보안 | API 키 서버사이드 관리, 워크샵 데이터 접근은 초대 코드 인증 필수 |

## 디자인 방향
- 다크모드 기본 — 프로젝터/대형 모니터 공유 시 가독성 확보
- 미니멀 대시보드 스타일 — 도구처럼 보여야 함. 마케팅 페이지가 아님
- 색상: 무채색 기반 + 포스트잇 색상으로 포인트
- 반응형은 데스크톱 우선. 태블릿은 참석자 입력용으로만 최소 지원
